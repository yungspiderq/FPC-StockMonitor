# 📦 StockMonitor — Монитор остатков товаров

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

**Автор:** yungspider

Следит за остатками товаров в автовыдаче и предупреждает, когда товар заканчивается —
чтобы лоты не «гасли» внезапно, а вы успевали пополнять запасы.

## Возможности

- 📦 **Мониторинг всех товарных файлов** из конфига автовыдачи
  (`storage/products/*.txt`), включая файлы, общие для нескольких лотов.
- ⚠️ **Предупреждение** — когда остаток опускается до порога (по умолчанию 5 шт.,
  настраивается глобально и **индивидуально для каждого лота**).
- 🚨 **Критическое уведомление** — товар КОНЧИЛСЯ (0 шт.): лот вот-вот будет
  деактивирован автовыключением Кардинала.
- ✅ **Уведомление о пополнении** — когда товар закончился и его добавили снова.
- 🔕 **Без спама** — каждое предупреждение отправляется один раз; повторно — только
  если товар поднимался выше порога и снова опустился (гистерезис).
- 📊 **Утренний дайджест** (опционально) — раз в день в заданное время сводка
  «какие лоты пора пополнить».
- 📋 **Меню в Telegram** (`/stock`): остатки по всем лотам (отсортированы — самые
  пустые сверху), пороги, интервал проверки, кнопка «🔄 Проверить сейчас».
- 💾 Настройки: `storage/plugins/stock_monitor/settings.json`.

## Установка

Скопируйте `stock_monitor.py` в папку `plugins/` и перезапустите Кардинала:

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-StockMonitor/main/stock_monitor.py -O plugins/stock_monitor.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование

1. Команда **`/stock`** (или `⚙️ Настройки` на странице плагина).
2. Главное меню: сколько файлов/лотов отслеживается, сколько с нулём (🚨)
   и сколько ниже порога (⚠️).
3. **📋 Лоты и остатки** — список с маркировкой:
   - 🚨 — товара нет (0 шт.);
   - ⚠️ — ниже порога;
   - ✅ — в норме.
4. Нажмите на лот → его страница: файл, остаток, все лоты, использующие файл,
   и кнопки:
   - **✏️ Порог для лота** — индивидуальный порог (если файл общий — применится ко всем его лотам);
   - **🗑 Сбросить порог лота** — вернуть глобальный порог.
5. Настройки главного меню:

| Кнопка | Действие |
|---|---|
| 🔄 Проверить сейчас | Немедленный проход мониторинга |
| ⚠️ Порог: 5 шт. | Глобальный порог предупреждения (1–100000) |
| ⏱ Интервал: 300с | Как часто проверять остатки (60–3600 сек.) |
| 📊 Дайджест: ВКЛ/ВЫКЛ | Ежедневная сводка проблемных лотов |
| 🕐 Время дайджеста: 09:00 | Когда отправлять сводку (по часам сервера) |

## Важно знать

- Плагин **не делает запросов к FunPay** — он читает товарные файлы на диске,
  поэтому не создаёт нагрузки на аккаунт и работает даже когда Runner остановлен.
- Отслеживаются лоты, у которых в конфиге автовыдачи указан `productsFileName`.
  Лоты без товарного файла (ручная выдача) не мониторятся.
- Если один файл используют несколько лотов — предупреждение приходит один раз
  (с перечислением лотов), порог берётся максимальный из индивидуальных.
- Дайджест отправляется только если есть проблемные лоты; время — по часам сервера.

## Состав репозитория

- `stock_monitor.py` — плагин (класть в `plugins/`).
- `tests_plugin_stock_monitor.py` — тесты (46 проверок на моках: сканирование,
  пороги, эскалация low→empty, гистерезис, дайджест, весь Telegram-UI, настройки).
  Запуск из корня FunPayCardinal:
  ```bash
  cp tests_plugin_stock_monitor.py /path/to/FunPayCardinal/
  cd /path/to/FunPayCardinal && pip install -r requirements.txt && python3 tests_plugin_stock_monitor.py
  ```
